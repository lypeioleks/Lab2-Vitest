# Лабораторна робота № 2 — Vitest

Варіант 3: `validateCoupon(code)`.

## Запуск

```bash
npm install
npm test
npm run coverage
```

Звіт HTML покриття формується у `coverage/index.html`.

## Специфікація варіанта 3

Промокод є коректним, якщо складається рівно з трьох великих латинських літер, дефіса та чотирьох цифр. Функція повертає `true` або `false`; некоректний формат не спричиняє винятку, оскільки специфікація варіанта цього не вимагає.
